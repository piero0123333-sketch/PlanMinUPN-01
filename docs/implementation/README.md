# Implementation Records

Esta carpeta contiene la trazabilidad técnica de cada módulo desarrollado por el equipo.

Cada módulo relevante debe crear su propio registro utilizando:

```text
docs/templates/MODULE_IMPLEMENTATION_TEMPLATE.md
```

Convención de nombres:

```text
IMP-001_data_loader.md
IMP-002_block_valuation.md
IMP-003_cutoff_grade.md
...
```

Un módulo no se considera cerrado sin su registro actualizado.
