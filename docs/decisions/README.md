# Engineering Decisions

Esta carpeta puede utilizarse para registrar decisiones transversales que afecten a más de un módulo o a la arquitectura general del proyecto.

Las decisiones específicas de un módulo deben registrarse también en su correspondiente `IMP-XXX`.

Formato sugerido:

```text
DECISION-XXX
Problema:
Alternativas:
Selección:
Justificación:
Impacto:
```
